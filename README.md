# Aether: Autonomous Life-Sentinel & Web3 Alpha Agent

Aether is a stateful, autonomous agent built on the **Cloudflare Agents SDK**. It is designed to manage complex life workflows including Computer Science academic tracking and Web3 economic automation.

### 🛠️ Technical Stack
- **Compute:** Cloudflare Workers (Agents SDK)
- **Database:** Cloudflare D1 (SQL) for persistent state
- **Intelligence:** Cloudflare Vectorize + BGE Large for RAG-based search
- **Payments:** Integrated **x402 Protocol** via Coinbase SDK
- **Scraping:** Hub Intelligence logic using Cloudflare Browser Rendering

### 🚀 Key Features
1. **Alpha Hunter:** Scans Web3 ecosystems for high-ROI airdrop opportunities.
2. **Academic Sentinel:** Manages CS lecture notes and bodybuilding hypertrophy tracking.
3. **Automated Execution:** Uses x402 to handle gas fees and transaction signing autonomously.
